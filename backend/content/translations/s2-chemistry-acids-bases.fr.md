## Les acides et les bases autour de vous

| Acides | Bases / alcalis |
|---|---|
| jus de citron, vinaigre, lait caillé | savon, cendre de bois, dentifrice |
| ont un goût aigre (ne goûtez jamais de produits chimiques au laboratoire !) | sont savonneux au toucher |
| font virer le papier de tournesol bleu au **rouge** | font virer le papier de tournesol rouge au **bleu** |
| contiennent des ions $\text{H}^+$ dans l'eau | les alcalis contiennent des ions $\text{OH}^-$ dans l'eau |

Un **alcali** est une base soluble dans l'eau.

## L'échelle de pH

L'échelle de pH va de 0 à 14 :

- **pH < 7** acide (plus le pH est bas, plus la solution est acide)
- **pH = 7** neutre (eau pure)
- **pH > 7** alcalin, ou basique (plus le pH est élevé, plus la solution est alcaline)

| pH | Exemple |
|---|---|
| 1 | acide gastrique |
| 3 | jus d'orange |
| 7 | eau pure |
| 8 | eau de mer |
| 11 | solution d'ammoniac |
| 13 | nettoyant pour four |

L'indicateur universel indique le pH par une couleur : rouge (acide fort) → vert (neutre) → violet (alcali fort).

## La neutralisation

Un acide et une base se neutralisent l'un l'autre :

$$\text{acide} + \text{base} \rightarrow \text{sel} + \text{eau}$$

$$\text{HCl} + \text{NaOH} \rightarrow \text{NaCl} + \text{H}_2\text{O}$$

Utilisations dans la vie quotidienne :

- Les agriculteurs ajoutent de la **chaux** (une base) aux sols acides pour améliorer les récoltes.
- Les comprimés **antiacides** neutralisent l'excès d'acide dans l'estomac.
- Le dentifrice neutralise les acides produits par les bactéries de la bouche.
